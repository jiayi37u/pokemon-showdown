# BasicAI 决策逻辑

## 概述

BasicAI 是最简单的 NPC AI，设计目标是**优先使用最大伤害的攻击招式**。

**难度**: Basic / Easy
**适用场景**: 新手训练、简单 NPC、野生精灵战斗

---

## 决策流程

```
收到请求
    │
    ▼
获取可用招式列表
    │
    ├─ 所有招式不可用？
    │       │
    │       ├─ 有后备精灵 → 随机切换
    │       └─ 无后备精灵 → 使用挣扎
    │
    └─ 有可用招式
            │
            ▼
        筛选攻击招式 (非 Status)
            │
            ├─ 有攻击招式 → 计算伤害，选最高
            └─ 只有状态招式 → 随机选一个
```

## 伤害计算

### 公式

```
估算伤害 = 基础威力 × STAB加成 × 属性克制 × 多段攻击次数
```

### STAB 加成

如果招式类型与攻击方的属性相同，伤害乘以 **1.5 倍**。

```
喷火龙 (火/飞) 使用火焰放射 (火)
→ 火属性匹配，×1.5
```

### 多段攻击 (v1.1.17+)

BasicAI 会正确计算多段攻击招式的期望伤害：

| 条件 | 2-5 次攻击期望 |
|------|---------------|
| 普通 | 3 次 |
| Skill Link | 5 次 |
| Loaded Dice | 4.5 次 |

特殊招式：
- **Surging Strikes**: 固定 3 次
- **Water Shuriken (Ash-Greninja)**: 固定 3 次

```
种子机关枪 (25 威力, 2-5 次) + Skill Link
→ 25 × 5 = 125 等效威力
```

### 重量招式 (v1.1.17+)

**Low Kick / Grass Knot** - 根据目标体重决定威力：

| 体重 | 威力 |
|------|------|
| ≥ 200kg | 120 |
| ≥ 100kg | 100 |
| ≥ 50kg | 80 |
| ≥ 25kg | 60 |
| ≥ 10kg | 40 |
| < 10kg | 20 |

**Heavy Slam / Heat Crash** - 根据体重比 (攻击方/防守方) 决定威力：

| 体重比 | 威力 |
|--------|------|
| ≥ 5 | 120 |
| 4 | 100 |
| 3 | 80 |
| 2 | 60 |
| ≤ 1 | 40 |

**体重修正**:
- Light Metal: 体重减半
- Heavy Metal: 体重翻倍
- Float Stone: 体重减半

### 属性克制

| 效果 | 倍率 |
|------|------|
| 免疫 | ×0 |
| 双抵抗 | ×0.25 |
| 抵抗 | ×0.5 |
| 普通 | ×1 |
| 克制 | ×2 |
| 双克制 | ×4 |

## 招式选择

1. 计算所有攻击招式的估算伤害
2. 排除伤害为 0 的招式（免疫）
3. 选择伤害最高的招式
4. 如果多个招式伤害相近（90% 以内），随机选择

### 示例

```
我方: 班吉拉斯 (岩石/恶)
对手: 土地云 (地面/飞行)

招式计算:
- 岩崩: 75 × 1.5(STAB) × 2(克制飞行) = 225 ★
- 咬碎: 80 × 1.5(STAB) = 120
- 地震: 100 × 0(免疫飞行) = 0 ✗
- 隐形岩: Status，跳过

选择: 岩崩
```

## 双打目标选择 (v1.1.17+)

在双打中，BasicAI 会评估所有对手并选择最优目标：

```
评估流程:
    │
    ├─ 单体招式: 遍历所有对手，计算每个招式对每个目标的伤害
    │
    ├─ 群攻招式: 计算对所有对手的总伤害，应用 0.75x 群攻衰减
    │
    └─ 选择 (招式, 目标) 组合中伤害最高的
```

### 目标位置格式

- `1`, `2` = 对手位置
- 群攻招式 (如地震、冲浪) 不需要指定目标

### 群攻招式评估 (v1.1.19+)

群攻招式计算**对所有对手的总伤害**，并应用双打的 0.75x 群攻伤害衰减：

```
群攻伤害 = (对 A 的伤害 + 对 B 的伤害) × 0.75
单体伤害 = 对选定目标的伤害

选择伤害最高的招式
```

**群攻招式类型**:
- `allAdjacentFoes` - 地震、热风、岩崩等（攻击所有相邻对手）
- `allAdjacent` - 冲浪、放电等（攻击所有相邻精灵，包括队友）

### 示例 1: 单体 vs 群攻

```
我方: 龙头地鼠 (地面/钢)
对手: 炽焰咆哮虎 (火/恶) [位置1], 甜茶壶 (草/幽灵) [位置2]

招式:
- 地震 (群攻, 100 威力) vs 炽焰咆哮虎: 100 × 1.5(STAB) = 150
- 地震 (群攻, 100 威力) vs 甜茶壶: 100 × 1.5(STAB) × 0.5(抵抗) = 75
- 地震 总伤害: (150 + 75) × 0.75 = 168.75

- 铁头 (单体, 80 威力) vs 炽焰咆哮虎: 80 × 1.5(STAB) × 0.5(抵抗) = 60
- 铁头 (单体, 80 威力) vs 甜茶壶: 80 × 1.5(STAB) = 120

选择: 地震 (168.75 > 120)
```

### 示例 2: 群攻被免疫

```
我方: 龙头地鼠 (地面/钢)
对手: 姆克鹰 (普通/飞行) [位置1], 路卡利欧 (格斗/钢) [位置2]

招式:
- 地震 vs 姆克鹰: 0 (飞行免疫地面)
- 地震 vs 路卡利欧: 100 × 1.5(STAB) × 2(克制) = 300
- 地震 总伤害: (0 + 300) × 0.75 = 225

- 岩崩 vs 姆克鹰: 75 × 2(克制) = 150
- 岩崩 vs 路卡利欧: 75 × 0.5(抵抗) = 37.5
- 岩崩 总伤害: (150 + 37.5) × 0.75 = 140.625

- 铁头 vs 姆克鹰: 80 × 1.5(STAB) = 120
- 铁头 vs 路卡利欧: 80 × 1.5(STAB) = 120

选择: 地震 (225 > 140.625 > 120)
即使姆克鹰免疫，对路卡利欧的高伤害仍使地震成为最优选择
```

### 示例 3: 单体更优

```
我方: 班吉拉斯 (岩石/恶)
对手: 土地云 (地面/飞行) [位置1], 路卡利欧 (格斗/钢) [位置2]

评分:
- 地震 vs 土地云: 0 (飞行免疫)
- 地震 vs 路卡利欧: 100 × 2(克制) = 200
- 地震 总伤害: (0 + 200) × 0.75 = 150

- 岩崩 vs 土地云: 75 × 1.5(STAB) × 2(克制) = 225 ★
- 岩崩 vs 路卡利欧: 75 × 1.5(STAB) × 0.5(抵抗) = 56.25
- 岩崩 总伤害: (225 + 56.25) × 0.75 = 210.9

- 咬碎 (单体) vs 土地云: 80 × 1.5(STAB) = 120

选择: 岩崩 (210.9 > 150 > 120)
```

## 换人逻辑

BasicAI **不会主动换人**，只在以下情况被迫换人：

1. 所有招式不可用（PP 耗尽或被禁用）
2. 当前精灵被强制换下（吼叫、龙尾等）

换人时**随机选择**一个可用的后备精灵。

---

## 不使用的功能

- ❌ 状态招式
- ❌ 强化招式
- ❌ 主动换人
- ❌ Dynamax / Mega 进化 / Z 招式

---

## 局限性

1. **不考虑能力值差异** - 只看威力和属性
2. **不考虑天气/地形** - 不知道晴天加强火系
3. **不考虑道具加成** - 讲究头带等不计入
4. **缺乏战略思考** - 不会预判对手行动
