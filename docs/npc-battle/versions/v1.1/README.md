## 核心功能

### 1. NormalAI 评分系统

**评分公式**:
```
最终得分 = 100 + 负面调整 + 正面调整
```

**负面评分** (扣分):
- 免疫检查 (-100): 属性免疫、神奇守护、特性免疫
- 被抵抗 (-5/-20): 单抵抗 0.5x、双抵抗 0.25x
- 低伤害 (-3/-8/-20): 伤害 < 33% / 20% / 10%
- 状态失效 (-10/-20): 目标已有状态、特性阻止
- 强化满级 (-100): 能力已+6
- 回复浪费 (-2/-5/-20): HP > 60% / 70% / 80%

**正面评分** (加分):
- 击杀奖励 (+20~+28): KO、先制 KO、保证 KO
- 高伤害 (+2~+10): 伤害 > 33%
- STAB (+3): 本系招式
- 克制 (+4~+15): 2x / 4x 克制
- 状态招式 (+12~+20): 睡眠、麻痹、灼伤
- 强化招式 (+8~+15): 龙舞、腹鼓、剑舞

### 2. BattleTracker - 对手状态追踪

解决服务端架构限制，通过监听协议消息追踪对手信息：

**追踪内容**:
- 对手精灵种类、属性、等级
- 对手特性、道具（暴露后）
- 对手能力变化 (boosts)
- 对手上一回合招式 (lastMove)
- 场地状态（天气、地形、hazards）

**协议消息示例**:
```
|switch|p1a: Alakazam|Alakazam, L50|100/100
|-ability|p1a: Alakazam|Magic Guard
|-boost|p1a: Alakazam|spa|2
|move|p1a: Alakazam|Psychic|p2a: Pikachu
```

### 3. 完整伤害计算

基于 CFRU `damage_calc.c` 实现：

**考虑因素**:
- 能力变化阶段 (boosts)
- 攻击方特性：大力士、活力、铁拳、技师、适应力等
- 防御方特性：厚脂肪、耐热、水泡、毛皮大衣、滤镜等
- 道具：讲究头带/眼镜、生命宝珠、专爱围巾等
- 天气：晴天/雨天对火/水系招式的影响
- 地形：电气/草地/精神场地 +30%
- 多段攻击：Skill Link (5次)、Loaded Dice (4.5次)
- 重量招式：Low Kick、Heavy Slam 威力计算

### 4. 双打支持

**多目标评估**:
- 单体招式针对每个对手分别评分
- 选择伤害/效果最大化的目标
- 群攻招式只评估一次

**队友保护**:
- 检查伤害招式是否误伤队友
- 检查状态招式是否对队友生效
- 群攻招式伤害缩放 (×0.75)
- 队友吸收特性加分 (蓄电、储水等)

**目标位置格式**:
```
1, 2    = 对手位置
-1, -2  = 己方位置（队友）
```

### 5. 换人决策

**换人条件**（动态阈值）:
```
maxAttackScore <= 95 && maxStatusScore <= 90
```

**换人评分**:
- 属性优势: 免疫对手招式 (+12)，抵抗 (+6)
- STAB 克制: 本系克制招式 (+8)，非本系 (+4)
- 生存能力: HP 百分比 / 10
- 危险惩罚: 被克制 (-5/-10)
