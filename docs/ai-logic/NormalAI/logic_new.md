# NormalAI 决策逻辑

## 概述

NormalAI 使用 **CFRU 评分系统** 进行招式选择，综合考虑伤害、状态招式、强化招式的价值。

**难度**: Normal / Smart
**适用场景**: 道馆馆主、普通训练家

---

## 决策流程

```
收到请求
    │
    ▼
构建战斗状态 (BattleState)
    │
    ▼
获取可用招式
    │
    ├─ 无可用招式 → 尝试切换或挣扎
    │
    └─ 有可用招式
            │
            ▼
        评估是否应该切换
            │
            ├─ 应该切换 → 选择最佳换入
            │
            └─ 不换人
                    │
                    ▼
                为所有招式评分
                    │
                    ▼
                选择得分最高的招式
```

---

## 评分系统

### 评分公式

```
最终得分 = 100 + 负面调整 + 正面调整
```

每个招式从 **100 分** 开始，根据各种因素加减分。

### 评分流程

```
基础分 100
    │
    ▼
负面评分 (扣分)
    │ - 免疫检查 (-100)
    │ - 被抵抗 (0.5x: -5, 0.25x: -20)
    │ - 低伤害 (<10%: -20, <20%: -8, <33%: -3)
    │ - 状态招式失效 (-10~-20)
    │ - 强化满级 (-100)
    │ - 回复浪费 (-3~-8)
    │
    ▼
正面评分 (加分)
    │ - 击杀奖励 (+20~+28)
    │ - 高伤害 (+2~+10)
    │ - STAB (+3)
    │ - 克制 (+4~+8)
    │
    ▼
最终得分
```

## 伤害计算

### 完整公式

```
基础伤害 = ((2×等级/5+2) × 威力 × 攻击/防御) / 50 + 2
最终伤害 = 基础伤害 × STAB × 属性克制 × 其他修正
```

### 考虑的因素

| 类别 | 内容 |
|------|------|
| 能力值 | 攻击/防御 + 能力变化阶段 |
| 攻击方特性 | 大力士、活力、铁拳、技师等 |
| 防御方特性 | 厚脂肪、耐热、水泡等 |
| 道具 | 讲究头带/眼镜、生命宝珠等 |
| 天气 | 晴天火+50%/水-50%，雨天相反 |
| 地形 | 电气/草地/精神场地 +30% |

### 对手能力值估算

AI 无法直接获取对手的个体值 (IV)、努力值 (EV) 和性格，使用以下默认值：

| 参数 | 值 | 说明 |
|------|-----|------|
| IV | 31 | 满个体值 (竞技标准) |
| EV | 85 | 平均努力值 (510/6 ≈ 85) |
| 性格 | 中性 | 不应用性格修正 |

**示例 - 胡地速度估算**:
```
基础速度 = 120
估算速度 = floor((floor((2×120 + 31 + floor(85/4)) × 50 / 100) + 5) × 1.0)
         = floor((floor(292 × 50 / 100) + 5))
         = floor(146 + 5) = 151
```

> 实际胡地 (Timid, 252 Spe) 速度为 189，估算值偏低但可用于基础判断。

### 多次攻击

| 条件 | 2-5次攻击的期望次数 |
|------|-------------------|
| 普通 | 3 次 |
| Skill Link | 5 次 |
| Loaded Dice | 4.5 次 |

特殊招式：Surging Strikes 固定 3 次。

### 重量招式

某些招式的威力取决于精灵体重：

**Low Kick / Grass Knot** (根据目标体重)

| 体重 | 威力 |
|------|------|
| ≥ 200kg | 120 |
| ≥ 100kg | 100 |
| ≥ 50kg | 80 |
| ≥ 25kg | 60 |
| ≥ 10kg | 40 |
| < 10kg | 20 |

**Heavy Slam / Heat Crash** (根据体重比: 攻击方/防御方)

| 体重比 | 威力 |
|--------|------|
| ≥ 5 | 120 |
| 4 | 100 |
| 3 | 80 |
| 2 | 60 |
| ≤ 1 | 40 |

**体重修正**:
- Light Metal: 体重减半
- Heavy Metal: 体重翻倍
- Float Stone: 体重减半

### 额外伤害 (回合结束)

在评估击杀能力时会考虑回合结束的额外伤害：

| 来源 | 伤害 |
|------|------|
| 普通毒 | 1/8 最大 HP |
| 剧毒 | 递增 (counter/16 最大 HP) |
| 灼伤 | 1/16 最大 HP |
| 沙暴 | 1/16 最大 HP (非岩/地/钢) |
| 冰雹 | 1/16 最大 HP (非冰) |
| 寄生种子 | 1/8 最大 HP |
| Salt Cure | 1/8 最大 HP (水/钢系: 1/4) |

**免疫条件**:
- Magic Guard 免疫所有额外伤害
- Poison Heal 不受毒伤害
- 岩/地/钢类型免疫沙暴
- 冰类型免疫冰雹
- Sand Veil/Ice Body/Safety Goggles 免疫天气伤害

### 击杀判断

```
能击杀 = 最大伤害 >= 对手当前 HP
保证击杀 = 最小伤害 >= 对手当前 HP
```

## 负面评分 (扣分)

### 免疫 (-100)

| 情况 | 扣分 |
|------|------|
| 属性免疫 (地面 vs 飞行) | -100 |
| 神奇守护 (非克制) | -100 |

### 特性免疫 (-20)

| 特性 | 免疫属性 |
|------|---------|
| 蓄电/引雷/电气引擎 | 电 |
| 储水/引水/干燥皮肤 | 水 |
| 引火 | 火 |
| 食草 | 草 |
| 飘浮/食土 | 地面 |

### 魔法镜 (-20)

对有魔法镜特性的对手使用可被反弹的招式 (隐形岩、鬼火等)。

### 状态招式失效 (-10~-20)

| 情况 | 扣分 |
|------|------|
| 对手已有该状态 | -10~-15 |
| 对手属性免疫 (电系免疫麻痹) | -20 |
| 对手特性免疫 (不眠免疫睡眠) | -20 |

### Magic Guard 状态招式检查 (-10)

对有 Magic Guard 特性的对手使用依赖持续伤害的状态招式会扣分：

| 招式 | 扣分 | 例外 |
|------|------|------|
| 鬼火 (Will-O-Wisp) | -10 | - |
| 剧毒 (Toxic) | -10 | 攻击方有 Venoshock 则不扣分 |
| 普通毒 | -10 | 攻击方有 Venoshock 则不扣分 |

**说明**: Magic Guard 使毒/烧伤的持续伤害无效，但如果攻击方有 Venoshock (毒击)，中毒状态仍有战术价值 (Venoshock 对中毒目标威力翻倍)。

### Covert Cloak 检查 (-3)

对持有 Covert Cloak (隐蔽斗篷) 的对手使用有附加效果的招式会扣分：

| 条件 | 扣分 |
|------|------|
| 招式有附加效果 (secondaryChance > 0) | -3 |
| 招式无附加效果 | 0 |

**受影响招式示例**:
- 十万伏特 (10% 麻痹)
- 冰冻光束 (10% 冰冻)
- 喷射火焰 (10% 灼伤)

### Salt Cure 检查 (-8~-10)

| 情况 | 扣分 |
|------|------|
| 目标已有 Salt Cure 状态 | -10 |
| 目标有 Magic Guard | -8 |
| 目标有替身 | -8 |

**说明**: Salt Cure 是 Gen 9 招式，40 威力但附加持续伤害状态。虽然 CFRU 没有实现此招式，但评分逻辑参考 CFRU 的 Leech Seed 模式。

### 强化招式浪费

| 当前等级 | 剑舞加分 |
|---------|---------|
| +0 | +10 |
| +2 | +5 |
| +4 | +2 |
| +6 | 0 (无法再提升) |

**HP 限制**:
- HP ≤ 25%: 不强化
- HP ≤ 40% 且较慢: 不强化
- HP ≤ 40%: -11 惩罚
- HP ≤ 60%: -6 惩罚

### 腹鼓检查 (-5~-100)

| 情况 | 扣分 |
|------|------|
| HP ≤ 50% | -100 (失败) |
| 唱反调特性 | -100 (反效果) |
| 50% < HP ≤ 70% | -5 (风险) |

### Counter/Mirror Coat 检查 (-3~-10)

| 招式 | 情况 | 扣分 |
|------|------|------|
| Counter | 对手无物理招式 | -10 |
| Counter | 对手是耐久型 | -3 |
| Mirror Coat | 对手无特殊招式 | -10 |
| Mirror Coat | 对手是耐久型 | -3 |
| Metal Burst | 先手 (会失败) | -10 |

### 重复设置 (-10)

- 天气已是目标天气
- 地形已是目标地形
- 隐形岩已存在
- 撒菱已满层
- 光墙/反射壁已激活
- 极光幕已激活或天气不是冰雹/雪

### 高血量回复 (-3~-8)

| HP | 回复招式扣分 |
|----|------------|
| > 80% | -20 |
| > 70% | -5 |
| > 60% | -2 |

### 接触招式风险 (-1~-5)

对带有接触特性/道具的对手使用接触招式会有惩罚：

| 特性/道具 | 效果 | 扣分 |
|----------|------|------|
| 铁刺/粗糙皮肤 | 造成 1/8 伤害 | -2~-5 |
| 静电 | 30% 麻痹 | -2 |
| 火焰之躯 | 30% 灼伤 | -2 |
| 毒刺 | 30% 中毒 | -2 |
| 木乃伊 | 替换特性 | -1~-5 |
| 爆裂尸体 | 灭亡之歌效果 | -5 |
| 凸凸头盔 | 造成 1/6 伤害 | -2~-5 |

**免疫条件**:
- Magic Guard 免疫伤害类接触效果
- Protective Pads 免疫所有接触效果
- 属性免疫 (电系免麻痹、火系免灼伤)

### 双打队友检查 (-5~-25)

**扩散招式伤害队友** (v1.1.20 更新):

根据实际伤害百分比缩放扣分:

| 情况 | 扣分 |
|------|------|
| 会击杀队友 | -25 |
| 伤害 > 50% HP | -15 |
| 伤害 > 25% HP | -10 |
| 低伤害 / 信息不足 | -5 |

**其他队友攻击**:

| 情况 | 扣分 |
|------|------|
| 攻击队友 (无特殊理由) | -15 |
| 对队友用有害状态招式 | -100 |

**例外** (不扣分):
- 队友有吸收特性 (蓄电/储水/引火/食草/飘浮/食土)
- 帮助/治愈铃声等有益招式

### 击杀奖励

|------|------|
| 能击杀 | +20 |
| 保证击杀 | 额外 +8 |

| 伤害占比 | 加分 |
|---------|------|

| > 60% HP | +6 |

### 属性加分

| 情况 | 加分 |
|------|------|
| STAB | +3 |
| 2倍克制 | +5 |

### 状态招式奖励

| 招式类型 | 基础加分 | 额外条件 |
|---------|---------|---------|
| 睡眠 | +12 | 对手是威胁 +20 |
| 麻痹 | +4 | 对手更快 +10 |
| 灼伤 | +4 | 对手是物攻手 +10 |
| 剧毒 | +4 | 对手是耐久型 +11 |

### 其他加分

| 招式类型 | 加分 |
|---------|------|
| 攻击强化招式 | +6~+18 |
| 防御强化招式 | +6~+12 |
| 入场伤害 | +4~+10 |
| 光墙/反射壁 | +6~+10 |
| 戏法空间 | +8~+14 |
| 挑拨 | +8~+12 |
| 交换招式 (U-turn) | +2~+8 |
| 吸血招式 | +1~+11 |
| 控制招式 (Disable/Encore) | +2~+7 |
| Salt Cure | +4~+15 |

### 吸血招式加分

根据当前 HP 决定吸血招式的价值：

| HP | 基础加分 | 后手额外加分 |
|----|----------|--------------|
| ≤ 30% | +8 | +3 |
| ≤ 50% | +5 | +3 |
| ≤ 75% | +3 | - |
| > 75% | +1 | - |

**特殊招式**: Oblivion Wing 额外 +2 (75% 回复)

### 控制招式加分 (Disable/Encore)

**重要**: 这些招式判断的是对手 **上一回合使用的招式** (lastMove)，而非对手的招式池。这对应 CFRU 中的 `gLastUsedMoves[bankDef]`。

| 招式 | 条件 | 加分 |
|------|------|------|
| Disable | 先手 + lastMove 是状态招式 | +4 |
| Disable | 先手 + lastMove 是攻击招式 | +2 |
| Disable | 先手 + lastMove 克制我方 | +2 |
| Disable | 后手 + lastMove 是状态招式 | +2 |
| Encore | 先手 + lastMove 是状态招式 | +4 |
| Encore | 先手 + lastMove 免疫我方 | +4 |
| Encore | 后手 + lastMove 是状态招式 | +3 |

**无效条件** (返回 0):
- 对手没有使用过招式 (lastMove 为空)
- 对手持有心灵香草 (Mental Herb)
- 对手已有相应状态 (已被 Disable/Encore)

**与移动池检查的区别**:
```
错误: 检查对手是否有强化招式 → rewardEncore 高分
正确: 检查对手上回合是否使用了状态招式 → rewardEncore 高分
```

### 防御强化评估

根据对手攻击类型决定是否强化防御：

| 情况 | 招式 | 加分 |
|------|------|------|
| 对手有物理招式 | 铁壁/棉花防守 | +8~+10 |
| 对手有特殊招式 | 瞬间失忆 | +8~+10 |
| 有 Body Press | 铁壁 | +10~+14 |
| 双防强化 | 宇宙力量 | +6~+12 |

**不强化条件**:
- 对手有 Unaware (无视强化)
- 对手有强制换下招式 (吼叫/龙尾)

| 天气 | 受益特性 | 加分 | 其他加分条件 |
|------|----------|------|--------------|
| 雨天 | Swift Swim | +10 | Water 属性/招式 +3 |
| 雨天 | Rain Dish/Dry Skin/Hydration | +4 | - |
| 晴天 | Chlorophyll | +10 | Fire 属性/招式 +3 |
| 晴天 | Solar Power/Flower Gift/Harvest | +4 | Solar Beam +4 |
| 沙暴 | Sand Rush | +10 | Rock 属性 +3 (SpD 提升) |
| 沙暴 | Sand Veil/Sand Force | +4 | 免疫伤害 +2 |
| 冰雹/雪 | Slush Rush | +10 | Ice 属性免疫 |
| 冰雹/雪 | Snow Cloak/Ice Body | +4 | Blizzard +4, Aurora Veil +5 |

**注意**: 天气招式不会因已有同天气而重复加分 (由负面评分处理)。

### 顺风评分

根据速度对比决定顺风的价值：

| 条件 | 加分 |
|------|------|
| 速度劣势 (攻击方较慢) | +12 |
| 速度优势 (攻击方较快) | +4 |
| 双打 | 额外 +4 |
| 有慢速强攻手后备 | +2/只 |

**无效条件** (返回 0):
- 顺风已激活

### Salt Cure 评分

Salt Cure (盐腌) 是 Gen 9 招式，40 威力岩石系物理攻击，命中后附加 `saltcure` 持续伤害状态。

**持续伤害**:
- 普通类型: 1/8 最大 HP / 回合
- 水/钢系: 1/4 最大 HP / 回合

**加分规则** (基于 CFRU Leech Seed 模式):

| 条件 | 加分 |
|------|------|
| 基础加分 | +3 |
| 目标是水系或钢系 | +10 |
| 目标是坦克型 (HP/Def/SpD ≥ 90) | +8 |
| 目标没有回复招式 | +2 |

**无效条件** (返回 0):
- 目标已有 Salt Cure 状态
- 目标有 Magic Guard 特性

**负面评分** (见负面评分部分):
- 已有 Salt Cure: -10
- Magic Guard: -8
- 替身: -8

**与 CFRU 的关系**: Salt Cure 是 Gen 9 招式，CFRU (Gen 7) 没有实现。评分逻辑参考 CFRU 的 Leech Seed 实现模式 (`ai_positives.c:914`, `ai_negatives.c:1703`)。

### 队友吸收特性加分 (v1.1.20 新增)

基于 CFRU ai_partner.c lines 62-179，在双打中攻击拥有吸收特性的队友可以获得加分。

**治愈型特性** (IncreaseHealPartnerViability):

| 特性 | 招式类型 | 队友 HP ≤ 50% | 队友 HP > 50% |
|------|----------|---------------|---------------|
| Volt Absorb | 电 | +10 | +6 |
| Water Absorb | 水 | +10 | +6 |
| Dry Skin | 水 | +10 | +6 |

**能力提升型特性** (IncreaseHelpingHandViability):

| 特性 | 招式类型 | 条件 | 加分 |
|------|----------|------|------|
| Motor Drive | 电 | 速度未满 | +8 |
| Lightning Rod | 电 | SpA 未满 + 有特殊招式 | +8 |
| Storm Drain | 水 | SpA 未满 + 有特殊招式 | +8 |
| Flash Fire | 火 | 有火系招式 | +8 |
| Sap Sipper | 草 | Atk 未满 + 有物理招式 | +8 |
| Justified | 恶 | Atk 未满 + 有物理招式 + 不会击杀队友 | +8 |
| Rattled | 恶/幽灵/虫 | 速度未满 + 不会击杀队友 | +6 |
| Steam Engine | 火/水 | 速度未满 + 不会击杀队友 | +10 |

**注意**: 这些加分与负面评分中的 `checkTargetingPartnerDamage` 的 -15 扣分相互抵消，最终结果为负 (如 -15 + 8 = -7)、零或正分。

## 换人逻辑

### 触发条件 (v1.1.26 更新)

当满足以下**两个条件**时，考虑换人：
- 最高攻击招式得分 < 95
- 最高状态招式得分 < 90

**阈值设计依据** (基于负面评分分析):

| 攻击场景 | 扣分计算 | 分数 | 是否触发 |
|---------|----------|------|----------|
| 本系被单抵抗 | 100 + 3(STAB) - 2(resist) | 101 | 否 (STAB 抵消) |
| 非本系单抵抗+低伤 | 100 - 2 - 2 | 96 | 否 (还能接受) |
| 非本系单抵抗+极低伤 | 100 - 2 - 5 | 93 | **是** (弱势) |
| 本系双抵抗 | 100 + 3 - 5 | 98 | 否 (STAB 抵消) |
| 非本系双抵抗+极低伤 | 100 - 5 - 5 | 90 | **是** (明显弱势) |

| 状态场景 | 扣分计算 | 分数 | 是否触发 |
|---------|----------|------|----------|
| 正常使用 | 100 + 正面加分 | 100+ | 否 |
| 对手已有状态 | 100 - 10~15 | 85~90 | **是** (无用) |
| Magic Guard 毒/烧伤 | 100 - 10 | 90 | **是** (无效) |
| 特性免疫/魔法镜 | 100 - 20 | 80 | **是** (完全无效) |

```
关键设计:
- 攻击阈值 95: 允许小扣分(单抵抗)，惩罚大扣分(双抵抗+低伤害)
- 状态阈值 90: 对手已有状态时触发，正常状态招式不触发
- 只有攻击和状态都弱势时才换人
```

### 换人评分 (v1.1.26 更新)

```
换入得分 = 属性防御分 + 属性进攻分 + HP分 + 危险惩罚
```

**属性防御分**:
| 条件 | 加分 |
|------|------|
| 免疫对手已知招式 | +12 |
| 抵抗对手已知招式 | +6/招式 (最多 2 招) |
| 被对手招式克制 | -5 (HP<60%) 或 -8 (≥2招克制) 或 -10 (低HP且克制) |
| 被对手本系属性克制 | -3 (额外) |

**属性进攻分**:
| 条件 | 加分 |
|------|------|
| 有本系克制对手的招式 | +8 |
| 有克制对手的招式 (非本系) | +4 |

**HP分**:
| 条件 | 加分 |
|------|------|
| HP 百分比 | / 10 (0-10 分) |
| HP ≥ 80% | 日志标记 "High HP" |

**换入决策**:
- 最佳换入得分 > 5 → 执行换人
- 最佳换入得分 ≤ 5 → 不换人 (继续使用当前招式)

## 对手信息处理

### 已知 vs 未知

| 信息 | 获取时机 | 未知时处理 |
|-----|---------|----------|
| 属性 | 上场时 | 从 Dex 查询 |
| 特性 | 特性触发时 | 空字符串，不扣分 |
| 道具 | 道具效果时 | 空字符串，不扣分 |

**重要**: 只有对手特性/道具被揭示后才会扣分！

### 示例

```
回合 1: 对手电龙上场，特性未知
→ AI 使用十万伏特，不会因蓄电扣分

回合 2: 十万伏特触发蓄电回复
→ BattleTracker 记录 ability = "voltabsorb"
→ 之后电系招式会扣 20 分
```

## 双打特殊处理

### 攻击方识别

双打时每只精灵需要独立做出决策。使用 `activeIndex` 参数标识当前行动的精灵：

```
request.active[0] → activeIndex = 0 → 第一只精灵
request.active[1] → activeIndex = 1 → 第二只精灵
```

### 多目标评估

对于单体攻击招式，AI 会评估所有对手并选择最优目标：

```
招式评估流程 (双打):
    │
    ▼
遍历所有对手
    │
    ├─ 对手 1: 评分招式
    ├─ 对手 2: 评分招式
    │
    ▼
选择得分最高的 (招式, 目标) 组合
    │
    ▼
返回招式和目标位置 (bestTargetPos)
```

**选择逻辑**: NormalAI 选择**对任一目标分数最高的招式**，而不是计算群攻总伤害。这与 BasicAI 不同。

**群攻招式多目标 KO 奖励** (v1.1.21):

群攻招式会为**每个被击杀的对手**获得独立的 KO 奖励：
- 第一个目标的 KO 奖励: 由 `rewardKnockout` 处理 (+20)
- 其他目标的 KO 奖励: 由 `rewardSpreadMove` 处理 (+20 per KO)

```
群攻招式额外奖励:
- 基础群攻: +6 (命中多目标) - 仅当对其他对手有效时
- 额外 KO: +20 (每个额外被击杀的对手)
- 先手双杀: +5 (安全性奖励)
- 额外 2HKO: +6
- 额外中等伤害: +3 (30%+ HP)
```

**v1.1.22 优化**: 基础群攻 +6 奖励仅在招式对**至少一个其他对手**有效时给予（有效定义：effectiveness > 0 且伤害 >= 15% HP）。这避免了对第二个对手免疫时仍给予群攻奖励的问题。

**示例 - 群攻 KO 两个对手 + 击杀队友**:
```
地震 vs 对手A (可击杀) + 对手B (可击杀) + 队友 (会被击杀):

评分:
100 (基础分)
+20 (KO 对手A - rewardKnockout)
+5  (先手 KO - rewardKnockout)
+6  (群攻命中多目标 - rewardSpreadMove)
+20 (KO 对手B - rewardSpreadMove)
+5  (先手双杀 - rewardSpreadMove)
-25 (击杀队友 - checkSpreadMoveHitsPartner)
= 131 分 (值得使用)

相比之前 (v1.1.20):
100 + 20 + 5 + 6 - 25 = 106 分 (低估了第二个 KO 的价值)
```

**示例 - 群攻 KO 一个对手，另一个免疫 + 击杀队友** (v1.1.22):
```
地震 vs 对手A (可击杀) + 对手B (飞行，免疫) + 队友 (会被击杀):

评分:
100 (基础分)
+20 (KO 对手A - rewardKnockout)
+5  (先手 KO - rewardKnockout)
+0  (无群攻奖励 - 对手B 免疫)
-25 (击杀队友 - checkSpreadMoveHitsPartner)
= 100 分

铁头 vs 对手B (50% 伤害):
100 (基础分)
+5  (中等伤害 - rewardHighDamage)
+3  (STAB)
= 108 分 ★

选择: 铁头 (108 > 100)
虽然地震能 KO 对手A，但对手B 免疫导致这实际是"单目标 KO + 杀队友"，
不如单体招式打有效目标。
```

**示例**:
```
龙头地鼠招式评估:
- 地震 vs 炽焰咆哮虎: 117 分 ★ (克制+4, STAB+3, 2HKO+8, 群攻+6, 打队友-10)
- 地震 vs 甜茶壶: 92 分 (抵抗-2, 低伤害-5, STAB+3, 群攻+6, 打队友-10)
- 岩崩 vs 炽焰咆哮虎: 112 分 (克制+4, 群攻+6)
- 岩崩 vs 甜茶壶: 101 分 (低伤害-5, 群攻+6)
- 铁头 vs 甜茶壶: 101 分 (STAB+3, 低伤害-2)

最高分: 地震 vs 炽焰咆哮虎 = 117
选择: 地震
```

**群攻招式** (如地震、冲浪) 对所有对手分别评分，选择最高分。群攻额外获得 +6 分 "Spread move hits multiple targets" 加成，但会打到队友时扣 -10 分。

### 目标位置格式

Pokemon Showdown 双打目标位置格式：
- `1`, `2` = 对手位置
- `-1`, `-2` = 队友位置
- `0` = 无特定目标

### 队友判断

使用**对象引用比较**判断目标是否为队友，而非 slot 数字比较（因为 slot 数字在双方可能相同）：

```typescript
// 正确
const isPartner = state.self.active.some(p => p === target);

// 错误 (slot 可能重复)
const isPartner = state.self.active.some(p => p.slot === target.slot);
```
