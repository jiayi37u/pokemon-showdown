## 不展开死亡成员配置

`profilesFor` 不规范化 `fainted` 或 HP 为零的成员配置。完整矩阵和部分查询仍返回原有零值格，存活成员的配置、权重及强化兑现判断不变。

冻结 48 加入场复用的独立诊断中，Slowbro 的 21058 次配置规范化有 3358 次用于死亡成员，011 的 603276 次有 28243 次。跳过后，两例完整 Assessment／pairs 返回序列、行动、节点和完整 reasoning 一致；仪表化耗时分别为 5.713 → 5.585 秒、53.116 → 51.945 秒。该时间含哈希校验开销，仅作为方向性证据。组合专项 187 项回归和 TypeScript 检查通过。

同一格式下模型对象身份重复率仅 0.12% 和 1.43%，因此不增加规范化 profile 的身份缓存。材料：`/tmp/hard-profile-normalization/REPORT.md`、`comparison.json`。

## 死亡对位格共享零值

死亡对位格共享一个只读 `Pair`；用于竞速计算及加权累加的 `zero()` 仍返回独立可写结果。生产消费者只读取矩阵，冻结诊断的深冻结与完整返回序列校验均通过。

011 的 20953 个完整局面缓存中有 81037 个死亡格。保持相同索引列表并排除临时标记容器后，在同一进程两次 GC 间只替换这些格，保留堆从 257567856 降至 216725392 字节，减少 38.95 MiB。它与仅缓存叶值的试验覆盖不同集合，不能直接相减或相加。

无冻结和哈希仪表的冷对照为 46.264 → 46.863 秒，RSS 也未改善；不宣称提速或峰值收益。保留依据是两行改动即可删除确定的重复对象，完整 Assessment、部分查询、行动、reasoning 和节点均一致。材料：`/tmp/hard-empty-pair/REPORT.md`。

## 接应用途确定后的短路

入场即倒下的成员已被健康条件排除出优势与 Pareto 比较，仍作为牺牲候选保留，不再计算其无用配置探针。已有优势接应者时，额外探针只需判断某成员是否存在会倒下的配置；一旦确认，后续配置不能撤销这一事实。无优势的自愿换人仍完整比较加权损失、存活与留场损失；只有此处需要计算 `stayLoss`。

011 的 14722 次探针中，6054 次不再影响选择；55818 次入场伤害查询中有 24114 次属于这些探针，55818 次留场伤害查询中有 51988 次无读取用途，两组节省有重叠。冻结对照的完整候选顺序、行动、reasoning、节点一致，Slowbro 为 5.516 → 5.414 秒，011 为 45.671 → 44.670 秒。RSS 混合，不声称内存收益。两项候选语义回归及全部 NPC 测试通过（1728 passing、1 pending）。未同时外提配置绑定副本，未修改评分或配置权重。材料：`/tmp/hard-entry-purpose/REPORT.md`。
