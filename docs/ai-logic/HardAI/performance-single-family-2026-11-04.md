# 每个配置族一个搜索代表

目标是用更少计算得到合理行动，允许经具体案例分析接受的小幅行动变化。搜索不设置节点、时间或配置数量上限，不改变策略评分权重。

## 公开证据优先

公开道具的正向识别复用 `BattleTracker`：`-heal`／`-damage` 的 `[from] item: ...` 通过通用 `handleItem` 记录道具。吃剩的东西未触发的排除补充在 `BattleEvidenceTracker`，复用 `excludedItems` 与 `refineOpponentModels`，没有另建道具识别系统。

证据要求 PS 回合末结算窗口开始时，有效公开快照中的对手已受伤、存活、道具可生效且没有回复封锁；到 `upkeep` 未出现回复才排除 Leftovers。满血后受到毒伤不满足该条件。沙暴 upkeep 可继续观察；治疗、道具／特性／身份变化等破坏证据连续性时放弃该窗口，不重建未知的中途状态。魔法空间、查封、回复封锁、笨拙及未排除的笨拙可能性保留不确定性。

`HardEvaluation` 对完整配置池应用公开证据筛选和队伍先验，搜索才调用 `searchOpponentModels`。每个配置族选择剩余候选中权重最高的完整配置，并列按原顺序选择，代表继承同族质量之和。道具、特性、性格、EV／IV 差异允许近似；公开否定的候选不能再作为代表。推断和搜索前初评保留全池，代表不写回 tracker。Random Battle 不按同名角色压缩。

证据改动单独提交为 `06b637893`。真实 PS 测试覆盖正常缺少回复、沙暴、真实 Leftovers 回复、满血后毒伤、回复／道具抑制，以及完整推断筛选后选择剩余同族代表。

唯一行动变化是 022 的河马兽由 Slack Off 改选 Whirlwind，与先前实验一致，用户明确接受该差异。没有出现额外行动变化。该样本各道具组合改变了两条路线的加权估值；目前定位到土地云和波尔凯尼恩的道具差异集合，未单独归因某个道具或具体续着。候选中含搜索上下界，不能把它们当成精确分差，也不把行动一致率解释为实力或胜率。

此前完整配置版本在同一 022 快照测得约 214.743 秒；本轮基线已经包含按族与道具压缩，所以新增收益比较的是 155.844 → 70.110 秒，不能将不同轮次计时混成同一组对照。
