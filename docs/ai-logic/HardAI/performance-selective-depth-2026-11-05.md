# 搜索深度、对位与配置拟合的消融验证

目标是行动合理、决策耗时低。行动差异用于定位需要审查的局面，不作为退化标签；完整两回合搜索也不是质量真值。基线为 `d835c61a9`，保留族内代表、公开证据筛选及换入致死回应覆盖。

## 消融范围与计时

使用现有 1499 快照中的固定 32 例：Gen 6／Gen 7 × 普通行动／接应四层各 8 例。每项实验独立运行 64 个冷 Node 进程，8 GiB heap，串行成对并交替两臂顺序，时间只计 AI 决策；无时间或搜索上限。各项均在运行前固定输入和变体，未挑最快重跑。不同实验的基线时间不混用，32 例总数不等于完整批次总体平均。

|消融|基线 → 变体|耗时降低|行动变化|判断|
|---|---:|---:|---:|---|
|所有根行动只结算首层|82.152 → 35.121 s|57.25%|12/32|存在明确短视行为，不采用|
|终点后备之间沿用根对位，更新在场行列|81.674 → 79.189 s|3.04%|0/32|收益不足，且会保留过期后备对位|
|从同一矩阵计算移除后备后的全队价值|81.557 → 81.430 s|0.16%|0/32|无明显收益，不增加实现|
|终点对位 HP 按 10% 近似，真实材料价值不变|82.361 → 83.113 s|−0.91%|1/32|无收益，不采用|
|优先保留 preset HP，找到首份相容努力值后停止|81.859 → 76.136 s|6.99%|0/32|收益不足且存在明显配点偏移，不采用|
|按战术风险决定是否展开第二拍|82.056 → 63.921 s|22.10%|0/32|全批揭示接应估值失真，不采用|
|选择性延伸，并保留新对位的首次行动机会|81.620 → 81.659 s|−0.05%|0/32|收益消失，不采用|

第一项对强制接应只评入场，连一次交战都没有，不能称作一回合战术搜索。普通行动的单层消融为 62.994 → 21.374 s，降低 66.07%；仍有 7/16 行动变化。

HP 近似只作用于终点对位的克隆配置；投影、候选及真实材料 HP 保留，受伤者不会被近似成满血触发气腰或多重鳞片。唯一变化是 140a T43 坚果哑铃面对席多蓝恩时，换己方席多蓝恩变为守住；不能仅凭该变化断言退化。近似的输入构造开销可能抵消缓存收益，此结果不证明所有 HP 抽象都无用。

首个可行努力值试验保留全部公开伤害、速度、道具约束和合法努力值预算，只改变不可观测能力值之间的选择偏好。拟合自身从 9.555 降到 3.428 s，但 9 例代表配点变化，其中土地云由 HP156／Atk176／Spe176 变为 HP4／Def116／Spe228，攻击 370 → 326。行动相同不能证明这种角色估计更合理。

## 为什么不能统一删掉第二拍

以下均基于同一公开快照、原配置质量和回应，使用原生投影核查；未把评分上下界当作精确值。

- **135a T19，烈箭鹰对沼王。** 浅层选择羽栖，面对地震后剩 110 HP，再羽栖后仅 40 HP，对手仍满血。鬼火面对热水后只剩 54 HP，但接羽栖后剩 74 HP，沼王降至 320 HP 且烧伤。第一拍单看血量会漏掉持续承伤改善。
- **140a T91，烧伤海兔兽对皮可西。** 浅层选择地震，月亮之力后仅 16 HP，下一拍被击倒；及时自我再生的两拍路线保留 399 HP。这里需要看到回复窗口，不是把原行动当正确答案。
- **129a T18，凯路迪欧对龙卷云。** 浅层牺牲 11 HP 玛狃拉换免费接应有实际用途；直接上地鼠的另一条路线则能下一拍高速旋转去钉、保留玛狃拉，并保留稍后再牺牲的选择。第二拍提供了不同战略路线的收益。
- **144a T10，席多蓝恩对 5 HP、被寄生的强化喷火龙。** 两拍最坏路径涉及对手换凯路迪欧。攻击打残凯路迪欧后的后续选择，与面对更高 HP 凯路迪欧时不同；保留候选／估值不单调的审计线索，不以直观“守住等寄生击倒”代替完整回应分析。

## 选择性延伸的实验规则

所有根行动仍展开相同的配置、回应、中转和击倒接应。第一拍结束后，按同一公开观察分组；任一组内世界出现以下情况，整组展开第二拍：

- 任一在场成员存在正强化、volatile 或正在蓄力。
- 存在尚待结算的祈愿或未来攻击。
- 任一方合法、无需延迟的攻击，按现有平均伤害足以击倒当前对手。

其余组使用首拍终点的全队估值。强制接应请求保持原有搜索，必须评估入场后的交战。组内隐藏配置共用深度，不读取真实隐藏配置、提交行动或后续日志。

这是混合深度的近似目标。quiet 分支的值是该新目标的终点值，不能称作完整两回合价值或其上下界。已经在第一拍击倒并完成补位的分支，依新在场局面判定是否继续；不是所有发生过击倒的分支都追加一回合。

固定 32 例中，203 个公开观察组／876 个世界停在首拍，555 组／1127 个世界继续。节点 21691 → 12080，减少 44.31%；普通行动 62.812 → 44.582 s，减少 29.03%。上述烈箭鹰和海兔兽案例的所有根值保留；144a T10 从 11.171 降到 5.351 s，守住及喷烟的精确值保留。其他候选值可以变化。

## 完整批次与战术审查

初始规则对全部 1499 份公开快照运行完成，无进程错误。普通行动有 165 处变化：Gen 6 为 60/550，Gen 7 为 105/782；167 次强制接应全部保持。fallback 从 94 降到 88，没有新增，其余日志差异仅为节点数字。少量回退消失不等于这些新选择已被证明更好。

回归和原生边界场景要求补充三个通用条件：根局面已有延迟效果时，评价其兑现后的行动；有效场地或侧场计时为 1 时，不在效果即将到期前停止；下一轮残伤致死时，保留回复或撤退的机会。它们不依赖精灵／招式特例。

补充条件的版本复用 830 例可证明不受影响的完整结果，另对 669 例整例重放。复用检查覆盖原运行访问的所有 quiet 组及其世界数；根延迟效果、到期计时、任何可能造成残伤的状态／天气／道具／volatile 均保守纳入重放，不拼接分支。最终 165 处变化逐一保持，节点 1534021 → 1115268，减少 27.30%。这个版本没有单独串行计时，不能把 22.10% 直接套用给它。

全部 165 处完成公开上下文筛查，按战术类型对高风险组核查原生路径。行动变化中既有合理取舍，也有终点选择造成的价值虚高：

- **135a T5，君主蛇飞叶风暴 → 觉醒火。** 对手可以换妙蛙花；觉醒火确实打换入者更痛，但该路线停在第一拍，飞叶风暴路线因正强化继续承担下一拍伤害。完整两拍中飞叶风暴仅优 2.132 分，而浅层给觉醒火的表面优势约 26 分。不能把觉醒火一概判错，也不能把这 26 分解释成战术收益。
- **141a T8，君主蛇飞叶风暴 → 觉醒岩。** 同样面对巨钳螳螂换入，觉醒岩只多打 7 HP，却失去飞叶风暴带来的 +2 特攻。飞叶风暴路线继续看到急速折返，君主蛇降至 61 HP；觉醒岩路线停在君主蛇 306 HP 的新对位。完整两拍根值为 −24.488／−34.471，混合深度把觉醒岩抬到 −18.008。这是承伤口径不一致的证据，不是用旧行动当标签。
- **132a T4，席多蓝恩换呆壳兽 → 牺牲君主蛇。** 305 HP 君主蛇被熔岩风暴击倒，喷火龙吃岩钉后免费补位，路线便停止；继续展开才看到拉帝欧斯接应。牺牲路线从完整两拍的 −133.733 被抬到 −92.404，对照直接呆壳兽路线为 −104.038。新接应的后续代价被遗漏。
- **134a T25，玛狃拉对凯路迪欧。** 冰柱坠击后玛狃拉阵亡，克雷色利亚免费入场即停止；直接换克雷色利亚则保住 211 HP 玛狃拉，并可下一拍月光回到 443 HP。完整两拍牺牲路线 −34.510、直接换人 −29.656；浅层把牺牲路线抬到 −17.653。
- **138a 天蝎王对龙卷云，挑衅 → 羽栖。** 羽栖确实在吃暴风后回复，并非满血空转。但路线停在未受挑衅的满血终点，没有计入下一拍更快龙卷云封锁回复的代价。六个相关快照来自同一旧轨迹，不能当六次独立退化。
- 地震改剧毒可以消耗回复核心、惩罚换入；144a 的报恩和地震在完整两拍中甚至精确同分。不能把所有差异归为错误。

因此再次做通用消融：只要第一拍发生接应检查点，或任一在场成员身份相对根局面改变，整个公开观察组都继续第二拍，保证新对位至少看到入场者的行动机会。相同固定 32 例为 81.620 → 81.659 s，节点 21691 → 21660，仅少 31 个；普通行动亦无提速。当前方案的主要收益来自跳过这些具有战术价值的计算，补齐后不满足显著收益要求，生产保留原有两回合搜索。

这不证明搜索深度永远不能减少。它定位了具体前提：若要依赖更浅终点，必须先使新接应、下一次承伤和行动机会的估值足够可靠。不能把所有没有立即一击击倒风险的局面视作稳定局面，也不能靠持续添加停止条件保留一项没有收益的实现。

## 当前成本画像

在固定 32 例中最慢的 0582／136a T5，对当前基线做单次 CPU 采样，决策窗口 15.505 s、6096 节点。按调用栈最近所属模块互斥归类：伤害适配与缓存 32.99%、对位 32.31%、投影 16.59%、GC 4.56%、推断 3.33%、评分 3.30%、搜索控制 2.94%、候选 1.62%。这是一个慢局面的画像，不是全批平均。

包含子调用的采样中，`evaluate` 为 57.32%，`directional` 为 35.20%；原生 vendor damage-calc 整个库仅 5.45%，其中伤害公式 2.50%，`DamageCache.key` 却占 8.56%。这些包含调用的比例不能相加。大头不仅是伤害公式，而是分支带来的对位组织、输入编码和状态复制；减少战术上不必要的展开比只优化伤害公式更有潜力。

## 独立正确性修复

独立提交：`6ce448844`。原生边界验证发现，PS 在天气计数归零时先结束天气，再处理未来攻击和普通残余；投影在残余之后才清天气，会多算一次沙暴／冰雹伤害、天气特性的扣血或回复，甚至让本应存活并吃到回复的成员提前倒下。`projection.endTurn` 按原生顺序先推进天气计数，其他天气生效回合保持对应效果。这项修复不依赖选择性深度，不声称带来性能提升。

天气修复验证：21 项原生 PS 定向对照；全部 NPC 回归 1782 passing、1 pending，TypeScript、修改文件 ESLint 和 diff 检查通过。所有搜索深度、HP 和配点近似均仅保留实验记录，没有进入生产实现。
