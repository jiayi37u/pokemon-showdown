# Hard 局面价值校准（待开展）

状态：2026-10-26 讨论记录，暂不开展系统校准、采样或参数调优。现行实现见 [Hard AI 逻辑](logic.md)。

## 问题与目标

两回合搜索依赖终点的规则估值。若终点估值与从该局面继续展开后的价值差异过大，同一条计划会在下一回合被放弃，连续决策可能产生低收益路线。

目标是校准价值函数的机制和权重，使浅层估值接近继续展开后的判断。实现使用纯规则，不依赖神经网络。持续加深线上搜索、强制执行上一回合计划或增加招式特例，都不能替代价值函数校准。

## 案例：玛纳霏萤火后被君主蛇逼退

战斗日志：`gen6ou-1793022042541`，Gen 6 OU。

- T2：玛纳霏换入，对手龙头地鼠使用隐形岩。
- T3：对手换君主蛇，玛纳霏使用萤火。
- T4：玛纳霏换火神蛾；火神蛾吃隐形岩和飞叶风暴，吃剩的东西回复后约剩 47% HP；君主蛇满血、特攻 +2。

T3 的搜索计划是萤火后留场使用精神强念，终点为残血 +3 玛纳霏对残血 +2 君主蛇。T4 重新搜索到 T5，留场后的阵亡或接应代价进入推演，于是放弃精神强念、改换火神蛾。君主蛇换入属于已展开的回应，并非意外暴露的新技能推翻计划。

现行兑现约束不让无法取得进攻进展的强化精灵继续依靠正能力等级贡献对其他后备的价值；这项修复仍不足以消除计划反转。T3 回放仍选萤火，T4 回放仍选火神蛾。

固定对手执行“换君主蛇 → 飞叶风暴”，按候选配置加权，兑现约束修复后的路线价值如下。分数均相对 T3 初始局面，越高越好；它们不是考虑所有对手回应后的完整行动价值。

| 我方两次行动 | 相对局面价值 |
| --- | ---: |
| 萤火 → 精神强念 | -44.5 |
| 精神强念 → 换火神蛾 | -45.4 |
| 热水 → 换火神蛾 | -52.0 |
| 萤火 → 换火神蛾 | -61.0 |

原候选筛选没有保留首回合精神强念：其评分约 91.5，被 100 分边界的评分断层规则剪掉。表中该路线来自单独展开。候选覆盖不足与终点评估误差是两个问题，校准时应分别记录，不能将未搜索某行动误诊为估值不佳。

## 校准方法

对同一个终点知识局面 `S`，记录规则估值 `V(S)`，再继续展开一回合，按现有双方决策与配置聚合规则得到 `V_expand(S)`。差值 `V(S) - V_expand(S)` 用于定位估值偏差。

比较必须保持相同的公开信息、候选配置及权重、伤害口径和计分基准。不能直接相减不同回合日志中的相对分数，也不能给展开的一方提供玩家隐藏配置。继续展开后的价值是更充分的校准参考，不是绝对真值；其终点仍受规则估值影响。搜索只给出上下界时，应记录边界，不能把它们当作精确值拟合。

先定位机制缺失，再调整已有因素的形式和权重。例如：

- 即将在下一次有效行动前倒下的精灵，是否仍贡献过多存活价值、进攻威胁和防守覆盖。
- 被迫换人时，强化丢失、后备入场伤害和承受攻击的代价是否充分体现，是否存在重复扣分。
- 当前威胁的固定扣分是否能表达不同精灵、不同后备条件下的实际损失。
- 打残对手带来的后备收割收益是否准确，避免为压低强化路线而抹掉真实收益。

用一批“终点估值—继续展开价值”配对检验共同机制，避免仅修改玛纳霏案例所需的数值。保留能兑现强化、有效换血、合理牺牲和安全接应等对照局面，检查误差与最终行动是否改善，以及是否出现反向偏差。评价目标是更可靠的行动排序和连续决策，不是仅追求分数误差变小。

具体采样范围、展开深度、参数调整方式和验收标准留待开展时讨论；本文不预设额外线上搜索层数或新固定权重。
