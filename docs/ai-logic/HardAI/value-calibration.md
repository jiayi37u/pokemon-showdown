# Hard 局面价值校准（案例诊断）

状态：从实战案例开展局面价值诊断，尚未建立系统校准或参数调优工具。首批同局面价值对照见 [自我对战诊断](iteration-2026-11-03.md#同一局面的价值对照)；现行实现见 [Hard AI 逻辑](logic.md)。

[完整批次的战略路线审计](iteration-2026-11-03-batch2.md#战略路线审计) 表明，继续展开参考也会受候选筛选影响：Slowbro 案例仅补回已有入场评价认可的 Weavile 回应，一回合参考即从 +103.44 降至 -35.79。定位静态价值偏差前，需要同时检查参考展开是否遗漏有战略意义的回应，不能直接将差值用于调整价值权重。

[连续 Protect 案例](iteration-2026-11-03-batch2.md#连续-protect-与回复响应缺失) 还显示，行动前 HP 的回复惩罚会让“先不攻击”的分支缺少对手回复响应，产生人为的行动价值差。Hard 的直接回复按实际行动时机和回复量计分；校准静态价值之前，应检查候选是否因前后口径不一致而出现这种差异。

[第三批 Tyranitar 路线校准](iteration-2026-11-03-batch3.md#tyranitar-循环的同口径延伸校准) 同时检查终点偏差和根回应覆盖：再展开一回合使条件路线优势从 70.364 缩到 4.188，但只有恢复被评分断层删除的合法 U-turn，完整两回合根排序才反转。该案例不能只靠调整场地或存活价值解决；需要先评估启发式剪枝遗漏战略回应的代价。

[016 的三回合控制校准](iteration-2026-11-04-control-calibration.md) 表明，某条条件计划推迟相同代价并多付损耗，仍不足以判定根行动错误：完整三回合参考继续选择 Rapid Spin，因其保留挡电和重铺岩钉的选项。临时控制导致的全队覆盖变化还需区分当前对手能否续控、到期前承伤和未来其他对手，不能免费清除控制或强制换人。

[玛纳霏的当前终点校准](iteration-2026-11-04-manaphy-calibration.md) 复现了计划反转：仅补回精神强念根候选不改变萤火选择，但固定相容回应的四条路线再展开一回合后排序反转。当前对位已经识别玛纳霏必败，主要差异来自下一拍的存活、接应与全队覆盖成本。这是条件路线的校准证据，不等于完整根行动结论。

[新批次六处差异复核](iteration-2026-11-05-cross-family-audit.md) 提供两个接应校准样本：131a T14 的牺牲地鼠换满血闪电鸟，以及 144a T3 的继续牺牲换掉残血强化喷火龙。条件终点继续展开的价值与静态值差异显著，但尚非完整三回合根优化。144a T5 则已通过只补回地震回应的同根对照确认换人风险遗漏，应先修候选覆盖，不能用估值权重补偿缺失回应。

[搜索深度消融](performance-selective-depth-2026-11-05.md) 提供了更多终点校准证据：只在没有立即击倒风险的终点停止，32 例可省 22.10% 耗时，但全 1499 例中出现 165 处行动变化。原生路径审查显示，牺牲后的免费补位、对手换入后的首次攻防，以及强化路线与非强化路线的不同展开深度，会制造显著的估值优势。要求新对位至少看到入场者的行动机会后，固定 32 例的耗时收益消失，因此该搜索简化未进入生产。后续校准应优先比较这些新接应终点的静态价值与下一次实际攻防代价；行动变化本身仍不是退化标签。

## 问题与目标

两回合搜索依赖终点的规则估值。若终点估值与从该局面继续展开后的价值差异过大，同一条计划会在下一回合被放弃，连续决策可能产生低收益路线。

目标是校准价值函数的机制和权重，使浅层估值接近继续展开后的判断。实现使用纯规则，不依赖神经网络。持续加深线上搜索、强制执行上一回合计划或增加招式特例，都不能替代价值函数校准。

## 案例：玛纳霏萤火后被君主蛇逼退

战斗日志：`gen6ou-1793022042541`，Gen 6 OU。

- T2：玛纳霏换入，对手龙头地鼠使用隐形岩。
- T3：对手换君主蛇，玛纳霏使用萤火。
- T4：玛纳霏换火神蛾；火神蛾吃隐形岩和飞叶风暴，吃剩的东西回复后约剩 47% HP；君主蛇满血、特攻 +2。

T3 的搜索计划是萤火后留场使用精神强念，终点为残血 +3 玛纳霏对残血 +2 君主蛇。T4 重新搜索到 T5，留场后的阵亡或接应代价进入推演，于是放弃精神强念、改换火神蛾。君主蛇换入属于已展开的回应，并非意外暴露的新技能推翻计划。

现行兑现约束不让无法取得进攻进展的强化精灵继续依靠正能力等级贡献对其他后备的价值；这项修复仍不足以消除计划反转。T3 回放仍选萤火，T4 回放仍选火神蛾。

固定对手执行“换君主蛇 → 飞叶风暴”，按候选配置加权，兑现约束修复后的路线价值如下。分数均相对 T3 初始局面，越高越好；它们不是考虑所有对手回应后的完整行动价值。

| 我方两次行动 | 相对局面价值 |
| --- | ---: |
| 萤火 → 精神强念 | -44.5 |
| 精神强念 → 换火神蛾 | -45.4 |
| 热水 → 换火神蛾 | -52.0 |
| 萤火 → 换火神蛾 | -61.0 |

原候选筛选没有保留首回合精神强念：其评分约 91.5，被 100 分边界的评分断层规则剪掉。表中该路线来自单独展开。候选覆盖不足与终点评估误差是两个问题，校准时应分别记录，不能将未搜索某行动误诊为估值不佳。

## 校准方法

对同一个终点知识局面 `S`，记录规则估值 `V(S)`，再继续展开一回合，按现有双方决策与配置聚合规则得到 `V_expand(S)`。差值 `V(S) - V_expand(S)` 用于定位估值偏差。

比较必须保持相同的公开信息、候选配置及权重、伤害口径和计分基准。不能直接相减不同回合日志中的相对分数，也不能给展开的一方提供玩家隐藏配置。继续展开后的价值是更充分的校准参考，不是绝对真值；其终点仍受规则估值影响。搜索只给出上下界时，应记录边界，不能把它们当作精确值拟合。

先定位机制缺失，再调整已有因素的形式和权重。例如：

- 即将在下一次有效行动前倒下的精灵，是否仍贡献过多存活价值、进攻威胁和防守覆盖。
- 被迫换人时，强化丢失、后备入场伤害和承受攻击的代价是否充分体现，是否存在重复扣分。
- 当前威胁的固定扣分是否能表达不同精灵、不同后备条件下的实际损失。
- 打残对手带来的后备收割收益是否准确，避免为压低强化路线而抹掉真实收益。

用一批“终点估值—继续展开价值”配对检验共同机制，避免仅修改玛纳霏案例所需的数值。保留能兑现强化、有效换血、合理牺牲和安全接应等对照局面，检查误差与最终行动是否改善，以及是否出现反向偏差。评价目标是更可靠的行动排序和连续决策，不是仅追求分数误差变小。

具体采样范围、展开深度、参数调整方式和验收标准留待开展时讨论；本文不预设额外线上搜索层数或新固定权重。
