# Hard 持续损耗估值

## 案例与口径

现有 batch 的 016a T20 中，龙头地鼠对满血闪电鸟使用 Rapid Spin，均值伤害为 17.125 HP，小于 Leftovers 的 23 HP 回复。攻击前按满血计算回复会得到零回复量，不能据此认为攻击能积累损耗。另一个独立竞速对照需要 361 次攻击才能击倒目标，不能按八次攻击计算其间承伤。

`outlook` 用攻击后的 HP 结算回合末效果，按净损耗估计击倒次数和持续攻击压力。净损耗不为正时不贡献直接攻击突破能力；首击击倒不结算被击倒者的回复；击倒次数不设固定上限。即时换入伤害 `switchPressure` 保留独立口径，回复配合毒／烧伤的状态路线仍参与评估。所有系数、实际伤害、搜索转移和根招式评分保持相同。

这仍是以当前一轮净损耗外推的近似，不逐轮模拟剧毒计数、HP 相关伤害或完整回复循环。它改善局面评价的具体偏差，不代表已解决无效消耗的全部决策原因。

## 同快照对照

冻结其他模块，只替换 `matchups`，7 个快照各运行两版，共 14 次正常完成。两版根原始 MoveScore 和保留的根候选逐项一致，最终行动也全部一致。

| 快照 | 两版行动 | 节点数：基线 → 净损耗估值 |
| --- | --- | ---: |
| 016 T20 | Rapid Spin | 400 → 394 |
| 024 T35 | Soft-Boiled | 136 → 136 |
| 024 T52 | Toxic | 864 → 864 |
| 024 T59 | Heal Bell | 655 → 655 |
| Slowbro T12 | Calm Mind | 660 → 661 |
| Diancie T11 | 换 Weavile | 106 → 106 |
| 011 T10 | 换 Tornadus | 26486 → 26087 |

016 的直接持续突破评价归零，但根行动仍为 Rapid Spin；024 的三个行动也不变。因此不能宣称这些循环已解决。该变化影响终点估值与部分分支，而非让指定回合匹配预设答案。

单次串行回放合计决策耗时 71.27 → 75.78 秒，011 为 49.21 → 52.23 秒。新增攻击后残余效果计算有成本，分支也会变化；共享宿主的单次数据不能精确区分这些成本与负载波动。这项提交是合理性修正，不宣称性能提升。
