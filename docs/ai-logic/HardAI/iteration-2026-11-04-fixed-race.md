# Hard 固定事件竞速的击倒次数

## 真实样本中的偏差

016 的对位计算包含 Seismic Toss 每击 100、目标 394 HP、Leftovers 每轮回复 24 的情形。固定事件轨迹为 `394 → 318 → 242 → 166 → 90 → 0`，需要 5 击；按 `ceil(394 / 76)` 估计成 6 击会多给一次回复，进而多算攻击者的承伤。

另一个方向是满血时回复被上限截断，第一轮净损耗可能大于后续。现有 7 个快照的 425233 次实际竞速计算中，45281 次（10.65%）与逐次固定事件结算的击倒次数不同：45255 次估得过长，26 次过短。修正不是统一偏向进攻或回复，而是保持结算顺序一致。

## 通用计算

公共回合末事件可精确编译成三个标量。在已知最大 HP、效果参数固定的条件下：

```text
HP <= knockoutThreshold 时结果为 0
否则结果为 min(ceiling, HP + change)
```

事件逐项构造这三个量，回复上限和早于后续回复发生的阵亡都保留。Hard 复用该变换，公共工具未提供 prepared 数据时继续原循环；有限 `beforeOrder` 也使用原顺序结算。Normal 的策略和结果不变。

`fixedDamageKnockoutTurns` 根据固定攻击伤害与此变换直接求次数，不逐回合循环。先判第一击结束；首轮回复封顶可能留下第二击击倒，必须在判断净回复量前单独处理。例如最大 HP 100、攻击 50、Wish 回复 200 后固定毒伤 60，轨迹为 `100 → 40 → 0`，不能因未封顶的净回复大于攻击就判定永远无法击倒。首轮之后仍可存活且净损耗不为正时，才判为无法击倒。

无法击倒时直接攻击 `check` 为零，不计算 `Infinity × 0`，也不凭稳定回复抬成直接攻击胜势。首轮压力和即时换入压力保留原口径，独立状态消耗路线仍参与。固定事件模型不推进 Toxic 计数、PP、HP 相关伤害或主动回复，不伪装成真实完整战斗。

## 分阶段对照

只将事件数组换成三标量变换：7/7 最终行动、完整 reasoning 和节点一致。单次串行总耗时 72.514 → 73.547 秒，不主张性能提升；该表示用于闭式竞速计算。

| 快照 | 两版行动 | 节点：首轮净率外推 → 固定事件闭式 |
| --- | --- | ---: |
| 016 | Rapid Spin | 394 → 391 |
| 024 T35 | Soft-Boiled | 136 → 136 |
| 024 T52 | Toxic | 864 → 864 |
| 024 T59 | Heal Bell | 655 → 679 |
| Slowbro | Calm Mind | 661 → 664 |
| Diancie | 换 Weavile | 106 → 106 |

7/7 行动一致，5 份 reasoning 有变化；016 和 024 T59 仅节点变化，其余三例还改变估值边界。单次总耗时 72.706 → 73.258 秒，不声称提速或内存收益。两阶段共 28 个独立进程正常完成，依赖固定为 c957；数学对照未混入独立 Encore 覆盖修复。
