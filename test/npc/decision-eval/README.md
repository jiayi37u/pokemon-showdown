# Hard AI 人工标注评测集

每道题由用户选择纳入并给出标准答案。只有用户明确授权才能新增题目或修改答案；AI 不根据自身选择、评分、胜负或测试结果调整标签。每题等权，选择的招式 ID 与标准答案一致才算正确；其他招式、换人或没有行动均算错误，不接受同分替代，不豁免不确定输入。

## 运行

在仓库根目录执行：

```bash
node build
node test/npc/decision-eval.js > /tmp/hard-decision-eval.json

# 只运行指定题目
node test/npc/decision-eval.js gen6ou-1793970481658-t4
```

stdout 为 JSON 报告，stderr 为进度与诊断。报告记录逐题答案、实际行动、正确性、决策耗时、搜索节点、推理日志和源码提交。全部正确退出码为 0，有错误为 1；输入或执行异常直接报错，不算通过。修改代码后需要重新构建，报告中的提交号不能识别未提交修改或过期的 dist。

评测串行执行，每题使用独立控制器和冷缓存；计时复用 `sim-battle/replay-decision.js`，不包含协议解析、状态重建和序列化。正确率是本人工标注集上的命中率，耗时和节点数单独报告，没有耗时或节点上限。评测独立于默认 Mocha 套件，错误答案保留为待解决问题，不为通过评测修改生产逻辑或标准答案。

## 输入与信息边界

`cases.json` 保存用户标签，`inputs/` 保存固定的公开协议及己方请求。协议止于目标回合的 `|turn|N`，不含双方该回合行动和未来事件；己方请求来自授权的己方配置及此前公开事件，不包含对手隐藏配置。运行时不读取实战 metadata、外部日志或 `/tmp` 快照。

请求用现有 `replay-audit.js` 的 `OwnRequest` 还原，初始属性与 PP 使用 Gen 6 引擎，己方性别使用公开队伍预览，队伍顺序由引擎执行已记录的己方首发选择恢复。每个历史回合的己方请求经生产状态构建器注册，再继续输入公开事件，保留证据追踪所需上下文；不重新执行历史 AI 决策。目标状态复用生产 Hard AI 决策入口，标签只用于决策结束后的判题。
